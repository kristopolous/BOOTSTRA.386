Introducing BOOTSTRA/386.

Bootstrap {{ .Site.Params.docs_version }}, drawn on an 8x14 character grid in the sixteen colors of an EGA card. Same markup, same classes, same JavaScript. Different decade.

Built for 1989.

One font, one size, one weight. Every row is fourteen pixels tall and every column is eight pixels wide, so everything lands where it would on a text mode screen.

Made for today.

Markup written for stock Bootstrap {{ .Site.Params.docs_version }} drops in unchanged. Every component, utility and plugin is here, from .btn to the offcanvas.

Packed with features.

Dialog shadows, hot keys in the menus, a blinking cursor, a loading animation, dithered backdrops and a black screen for the night shift.
